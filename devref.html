Core HTML Tags Reference

Document Structure

  • <!DOCTYPE html> - Declares document as HTML5
  • <html lang="en"> - Root element of the page
  • <head> - Metadata, title, fonts, styles
  • <body> - Main visible content container
  • <meta charset="UTF-8"> - Character encoding
  • <title> - Page title in browser tab

Semantic Layout Tags

  • <header> - Top site header / navigation zone
  • <nav> - Navigation link groups
  • <main> - Primary unique page content
  • <section> - Thematic grouping of content
  • <article> - Independent reusable content block
  • <aside> - Sidebar content / secondary info
  • <footer> - Bottom page information / copyright

Text & Content

  • <h1> to <h6> - Section headings (H1 top level)
  • <p> - Paragraph text block
  • <a href="..."> - Hyperlink
  • <strong> - Bold text (important)
  • <em> - Italic text (emphasis)
  • <span> - Inline text container for styling
  • <div> - Block-level layout container

Lists & Tables

  • <ul> / <ol> - Unordered / Ordered list
  • <li> - Individual list item
  • <table> - Table wrapper
  • <tr> - Table row
  • <th> - Table header cell
  • <td> - Table data cell

Forms & Inputs

  • <form action="..." method="POST"> - Form wrapper
  • <label for="id"> - Text label for inputs
  • <input type="text" id="id"> - Text input field
  • <textarea> - Multi-line text input
  • <button type="submit"> - Action button
  • <select> & <option> - Dropdown menu
